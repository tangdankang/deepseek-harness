# v1.17 — 可信身份生命周期事件

## 新增

- 新增统一身份生命周期事件入口 `POST /api/v1/webhooks/identity/events`。
- 新增停用、离职、恢复、成员关系变化和资料变化五类规范事件。
- 新增独立 HMAC 密钥、可信来源、时间窗、事件 ID 防重放和员工级单调序号校验。
- 新增不可变身份事件账本、员工访问状态和 Schema v9 迁移。
- 生命周期事件即时撤销员工全部会话；停用状态同时约束浏览器、身份票据和 DEAP 工具链。

## 安全规则

- 非恢复类资料变化不能解除停用。
- 相同事件 ID 不同正文、乱序、过期、未来、未知来源、未知字段和签名错误均拒绝。
- 生产启动强制提供与其他用途不复用的 `IDENTITY_EVENT_SECRET`。

## 兼容性

- 现有登录、工单和 DEAP 13 工具契约保持兼容。
- 开发模式未配置事件密钥时入口关闭；生产模式强制启用。
- 真实钉钉或 IAM 回调字段由公司身份网关映射到稳定内部契约。
