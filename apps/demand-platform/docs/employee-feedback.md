# 员工结果反馈

反馈用于回答“员工是否确认解决、是否满意”，不能由模型自行推断。

## 安全边界

- 仅员工明确点击或在当前消息中明确评价时记录，`employeeConfirmed` 必须为 `true`。
- 员工只能反馈本人的真实会话、统一需求或人工受理事项。
- 每名员工对同一对象只能提交一次；重放同一幂等请求安全复用，不允许静默修改历史评价。
- 评分为 1—5；原因使用白名单编码；不接收自由文本，减少在分析数据中二次收集敏感信息。
- 反馈表只保存密钥化员工哈希，不保存明文员工编号；审计按公司访问权限管理。

## 指标口径

- `feedbackResponseRate`：反馈数 / 有会话编号的去重会话数；
- `employeeConfirmedResolutionRate`：确认解决反馈 / 全部反馈；
- `positiveRatingRate`：4—5分反馈 / 有评分反馈；
- `averageRating`：有评分反馈的平均分。

这些指标只代表反馈样本，必须同时展示反馈响应率和样本数，不能把极少数高分外推到所有用户。

## DEAP工具

`record_feedback` 只接受结构化字段。Agent 不得根据“谢谢”等模糊表达自动判定已解决，也不得编造评分；信息不明确时应直接询问员工。
